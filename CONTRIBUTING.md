# If you want to add a package PLEASE follow this intructions <3
- Make a fork
- Create a folder for package
- Create a file with the name "template" in the folder for new package
- Test your package with [vouru](https://github.com/javiercplus/vouru/tree/main) or use [xbps-src ](https://github.com/void-linux/void-packages)
- Send a PR / PULL REQUEST
- You can make a package from tarball's, debs, aur's, appimage etc... 
- If you have a question you can answern in issues <3 

### Note: if you made a template for a appimage use the location /usr/local (for .desktop and icons) and /opt/app* for content of the appimage
